# GitHub Organization and Repository Structure

Two orgs for different purposes:

## Textbook Org

Will host the repo and live site for the mkdocs textbook.

Will host related source code for this book, with examples in their own repos.

## Assignments Org

Will need to be public as well, but not "advertised" in the way the textbook is. It's meant for Ivy Tech students.

Starter code will be provided as template repositories.

If someone else wants write permissions I'm fine with it. They just need to know that students will be prompted to pull latest changes if they update code mid-course, and that leads to messes with students.
