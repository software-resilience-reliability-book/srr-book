# Diagnosing Errors

Software error provide us with a valuable signal that something is not working as expected. Modern compilers, IDEs, and runtimes don't typically just crash a program without leaving behind some kind of problem details; however, it is up to us to put these details to use.

In this chapter we will examine errors that can occur at different stages of the software development process. These include compile-time, runtime, and logic errors. We will also explore techniques to diagnose these errors and to keep our applications running smoothly when they happen.
